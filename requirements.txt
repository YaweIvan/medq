MedQ Project Requirements

Runtime requirements
- PHP 8.2 or later
- Composer
- Node.js 18 or later
- npm
- MySQL 5.7+ or MariaDB compatible version
- Web server or local stack such as XAMPP/WAMP

Backend dependencies
- laravel/framework ^12.0
- laravel/tinker ^2.10.1
- maatwebsite/excel ^3.1

Development dependencies
- fakerphp/faker ^1.23
- laravel/pail ^1.2.2
- laravel/pint ^1.24
- laravel/sail ^1.41
- mockery/mockery ^1.6
- nunomaduro/collision ^8.6
- phpunit/phpunit ^11.5.3

Frontend dependencies
- @tailwindcss/vite ^4.0.0
- axios ^1.11.0
- concurrently ^9.0.1
- laravel-vite-plugin ^2.0.0
- tailwindcss ^4.0.0
- vite ^7.0.4
- @fortawesome/fontawesome-free ^7.2.0
- bootstrap ^5.3.8
- chart.js ^4.5.1

Recommended setup steps
1. Run composer install
2. Run npm install
3. Copy .env.example to .env and configure database credentials
4. Create a database named medq
5. Run php artisan key:generate
6. Run php artisan migrate --seed
7. Run npm run dev during frontend development
8. Run php artisan serve for local backend testing

Notes
- The current Composer manifest requires PHP 8.2, which is newer than the PHP 8.1+ note in README.md.
- This file documents project requirements in plain text; it is not a Python requirements file.
